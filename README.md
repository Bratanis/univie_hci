# About this project

This is an android application that was developed for the course "human computer interaction" in the University of Vienna.
The idea is to develop the front end of a social media app, simiar to be real or instagram, where users can post a random good thing they did that they and view what good deeds their friends have posted.
This was a group project, developed by Marius Hasler, Alfons Sebastian, Jonathan Funkekaiser and me. For some reason while transfering this repository to github, all of the commits from the first two group members got grouped with Jonathan's. I was resposible for developing the camera functionallity of the application, including taking and uploading pictures (front and back camera) as well as uploading existing photos from the gallery.
